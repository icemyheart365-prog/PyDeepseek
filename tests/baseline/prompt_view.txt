help() - List enabled commands and concise usage information.
pwd() - Return the configured library root or current approved working directory; do not expose unrelated device paths.
ls(path, format, all, sort) - List entries in a directory. This is a structured command, not arbitrary shell input.
stat(path) - Return metadata for one file or directory without returning its content.
wc(path, count) - Count bytes, lines, and words for a text file without returning the file body.
sha256(path) - Calculate a file's SHA-256 digest without returning its content.
search_files(path, pattern, recursive) - Find files by a simple filename pattern and return paths only.
grep(path, pattern, regex, ignore_case, max_matches) - Search text files for a literal or regular-expression pattern and return matching lines. [needs confirmation]
head(path, lines) - Return the first N lines of a text file. [needs confirmation]
tail(path, lines) - Return the last N lines of a text file. [needs confirmation]
cat(path) - Read the complete contents of a text file. Use head, tail, or grep first when possible. [needs confirmation]
cancel() - Cancel the currently pending command or confirmation request.

web_fetch(url, timeout) - Fetch one public HTTP/HTTPS webpage through DeepSeek Fetch API and return its Markdown content. [needs confirmation]
